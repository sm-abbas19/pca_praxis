Defense-in-Depth

Engineered for Safety

We assume the LLM can make mistakes. A refreshed, multi-layered pipeline combines heuristic gating, policy checks, and human approval before any command runs.

  • 🚫
    Intent Heuristics

    Natural-language vetting inspects verbs, objects, and command-style arguments to block prompts like "list provinces of pakistan" before they reach the model.

  • 📋
    Strict Policy Enforcement

    The model is instructed to reply with echo 'Unsupported request: expecting a bash task' when no safe single command exists, reinforcing the allowlist.

  • 👁️
    Human-in-the-Loop

    No command runs automatically. The user must review the plan and click "Execute", with special warnings for risky actions.

  • 🧠
    Consistent UX Feedback

    When a prompt is rejected, the frontend now anchors the warning beside the user message instead of a global banner, clarifying why execution stays disabled.

def _looks_like_shell_request(text):
    lowered = text.lower().strip()
    if not lowered:
        return False

    tokens = lowered.split()
    if tokens and tokens[0] in _TASK_VERBS:
        if len(tokens) == 1:
            return True
        remaining = tokens[1:]
        if any(
            t in _TASK_OBJECTS
            or t.startswith('-')
            or re.search(r"[./\\]", t)
            or re.search(r"\d", t)
        for t in remaining):
            return True

    words = set(re.findall(r"[a-z]+", lowered))
    return bool(words & _TASK_VERBS and words & _TASK_OBJECTS)

Performance Engineering

Optimizing local LLM inference on consumer hardware (Intel Core i5-1235U).

Adaptive Threads

Auto (up to 12)

Thread count now derives from os.cpu_count() with optional LLM_NUM_THREADS overrides for hybrid-core tuning.

Context Window

3072 Tokens

Default context grew for longer chats and remains configurable through LLM_NUM_CTX.

Warm Start Clock

60 s Timeout

Requests honor a configurable LLM_REQUEST_TIMEOUT with a five-minute LLM_KEEP_ALIVE to balance responsiveness and resource usage.
